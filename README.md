# python_bigdata

Python을 활용한 데이터 처리 및 분석 실습 내용을 정리한 저장소입니다.  
Jupyter Notebook을 중심으로 다양한 데이터 처리 과정과 분석 과정을 기록하였습니다.

## 프로젝트 개요

본 저장소는 Python 기반 데이터 분석 학습 과정에서 작성된 코드와 실습 파일을 포함하고 있습니다.  
주요 목적은 데이터 처리 과정과 분석 흐름을 이해하고, 이를 반복적으로 실습하는 것입니다.

## 구성

본 저장소는 다음과 같은 형태로 구성되어 있습니다.

- Jupyter Notebook (`.ipynb`) 파일
- 데이터 파일 (CSV 등)
- 데이터 처리 및 분석 코드

※ 각 Notebook 파일은 개별 실습 단위로 구성되어 있으며,  
데이터 처리 → 분석 → 결과 확인의 흐름을 포함하고 있습니다.

## 주요 내용

- Pandas를 활용한 데이터 처리
- 데이터프레임 및 시리즈 구조 이해
- CSV 파일 불러오기 및 저장
- 데이터 전처리 및 기초 분석
- 간단한 데이터 시각화
