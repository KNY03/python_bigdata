# python_bigdata

Python을 활용한 빅데이터 처리 및 데이터 분석 기초 과정을 학습하고 정리한 프로젝트입니다.  
데이터 수집, 전처리, 분석, 시각화까지의 전체 데이터 파이프라인을 이해하는 것을 목표로 합니다.

## 프로젝트 개요

본 프로젝트는 Python 기반의 데이터 분석 환경에서  
대용량 데이터(Big Data)를 효과적으로 처리하고 분석하기 위한 기초 역량을 강화하기 위해 수행되었습니다.

특히 다음과 같은 흐름을 중심으로 구성되었습니다.

- 데이터 수집 및 파일 처리
- 데이터 전처리 및 정제
- 데이터 구조 이해 (Series, DataFrame)
- 대용량 데이터 처리 방식 학습
- 분석 결과 시각화 및 해석

## 주요 학습 내용

- Pandas를 활용한 데이터 처리
- CSV / TXT 파일 대용량 데이터 로딩
- 데이터 정제 (결측치 처리, 형 변환)
- 데이터 집계 및 그룹화 (groupby)
- 통계 기반 데이터 분석
- Matplotlib / Seaborn 시각화
- 데이터 분석 파이프라인 이해
